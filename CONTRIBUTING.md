# Contributing to Privacy-Preserving AI Browser Agent

First off, thank you for considering contributing to our SIH26171 project! It's people like you that make open-source a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, please make sure to check if there is an existing issue. If not, open a new issue using our provided templates!

## Setting up your environment

1. Fork the repo and create your branch from `main`.
2. Follow the Installation & Setup guide in the `README.md` to start the backend and build the Chrome extension.
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes.

## Pull Request Process

1. Ensure your code adheres to the existing style.
2. Update the `README.md` or `docs/` with details of changes to the interface or architecture if applicable.
3. Submit a Pull Request using the provided PR template.
4. A project maintainer will review your PR and merge it once approved.

## Code of Conduct
By participating in this project, you agree to maintain a respectful and welcoming environment for everyone.
